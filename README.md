# 🛒 Shop Management System

A desktop-based Shop Management System developed using **Java**, **Java Swing**, and **Object-Oriented Programming (OOP)** principles. This application helps small businesses efficiently manage products, track sales, monitor inventory, and calculate total revenue through a simple and user-friendly graphical interface.

---

## 📖 Project Overview

The Shop Management System is designed to simplify inventory and sales management for small businesses. It allows users to add products, update inventory, process sales, maintain sales records, and automatically calculate total revenue. All data is stored using text files, ensuring information is preserved even after the application is closed.

---

## ✨ Features

- ➕ Add New Products
- ✏️ Update Product Information
- 🛒 Sell Products
- 📦 Automatic Stock Management
- ⚠️ Low Stock Alert
- 📋 Sales Log
- 💰 Total Revenue Calculation
- 💾 File-Based Data Persistence
- 🖥️ User-Friendly Java Swing GUI
- ✅ Input Validation & Error Handling

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/jmfaheemhassan/shopemanagment.git
```

### Open in VS Code

Install Java Extension Pack.

### Build Project

```bash
mvn clean install
```

### Run

Run `Main.java`

or

```bash
mvn exec:java
```
